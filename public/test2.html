2. What FMCSA Provides (Base Dataset)

The FMCSA dataset is a flat, single-record snapshot per carrier. It contains the following core categories of information:

2.1 Carrier Identity & Registration
  • Legal name, DBA name, organization type (Corporation, LLC, etc.)
  • USDOT number, MC docket number, EIN / DUNS number
  • Physical and mailing address, telephone, fax, email
  • Date added to FMCSA, MCS-150 filing date and mileage
2.2 Operating Authority
  • Current authority status: Common, Contract, Broker (Active / Inactive)
  • Operation classification (Authorized for Hire, Exempt, Private, etc.)
  • Interstate vs. intrastate carrier designation
  • Carrier operation type (Property, Passenger, Household Goods, Hazmat)
2.3 Fleet & Driver Statistics
  • Total power units, trucks, tractors, trailers, buses
  • Owned vs. leased breakdown by vehicle category
  • Total drivers, CDL drivers, interstate/intrastate breakdown
  • Annual mileage as self-reported on MCS-150
2.4 Safety Data (Current Snapshot Only)
  • Current safety rating: Satisfactory / Conditional / Unsatisfactory
  • BASIC measure scores and percentiles (Unsafe Driving, HOS, Vehicle Maintenance, etc.)
  • Total crashes, fatalities, injuries, tow-aways (aggregate counts)
  • Total inspections, driver OOS count, vehicle OOS count
  • Latest review type and date
2.5 Insurance (Active Policies Only)
  • BIPD insurance amount on file and required minimum
  • Cargo insurance amount on file
  • Broker surety bond amount on file and required
2.6 Cargo Classifications
  • Cargo type flags: Fresh Produce, Refrigerated Food, General Freight, Chemicals, Hazmat, Livestock, etc.
